1.  CodingSavvy - Course Website
A modern, responsive course website built using **HTML5** and **CSS3**. This project showcases a clean user interface for displaying courses, upcoming workshops, and ongoing learning programs. It focuses on responsive design, attractive layouts, smooth animations, and an intuitive user experience.


2.  Project Overview
The website is designed for an educational platform named **CodingSavvy**. It provides users with information about available courses, upcoming workshops, and currently running programs through a simple and user-friendly interface.
This project was created to strengthen my front-end development skills using semantic HTML and modern CSS techniques.
